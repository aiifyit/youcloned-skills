# Content Repurposer Skill

One piece of content should become 10-20 pieces. Your job is to take a long-form source and systematically extract maximum value across every channel.

## Input Handling

Accept content in any of these forms:
- A transcript (text pasted or file uploaded)
- A video URL (extract transcript via YouTube API if available)
- An audio file reference (transcribe first)
- A blog post URL (fetch and extract content)
- A raw document or notes

## The Repurposing Framework

From ONE long-form piece, produce:

### Tier 1: Direct Derivatives
1. **Blog post** — Full written version of the content (if source was video/audio), or SEO-optimized rewrite (if source was already written)
2. **Email newsletter** — Condensed version with one key takeaway and CTA
3. **YouTube video description** — SEO-optimized with timestamps, links, and keywords

### Tier 2: Social Posts (5-10 per source)
4. **Twitter/X posts** — 5-10 standalone tweets, each built around one insight or quote
5. **Twitter/X thread** — One 5-10 tweet thread covering the main framework or story
6. **LinkedIn posts** — 3-5 narrative-style posts, each with a different angle on the content
7. **Instagram carousel** — 5-10 slide educational carousel (provide text for each slide)
8. **Instagram/TikTok/YouTube Short script** — 3-5 short-form video scripts (15-60 seconds each), built from the most compelling moments

### Tier 3: Evergreen Assets
9. **Quote graphics** — 3-5 quotable lines formatted for image creation
10. **FAQ entries** — Any questions answered in the content, formatted as FAQ pairs
11. **Lead magnet excerpt** — If the content teaches a framework, extract it as a standalone PDF/guide

## Process

1. **Consume the source** — Read/process the entire piece
2. **Identify the gold** — Find the 5-10 most compelling moments:
   - Surprising stats or claims
   - Strong opinions or hot takes
   - Memorable metaphors or analogies
   - Step-by-step frameworks
   - Personal stories with lessons
   - Quotable one-liners
3. **Map to outputs** — Assign each golden moment to the appropriate output formats
4. **Write all derivatives** — Produce each piece, tailored to its platform
5. **Present the package** — Deliver everything organized by platform with a suggested posting schedule

## Quality Rules

- Every derivative must stand alone — a reader shouldn't need the source to understand it
- Match the user's voice and tone from their profile
- Each piece needs its own hook — don't just copy-paste the opening of the source
- Short-form scripts should be the most engaging moments, not summaries
- Social posts should provoke engagement (reactions, comments, shares) — not just inform
- Always attribute: "From my latest [podcast/video/article] on [topic]" where appropriate

## Output Format

Organize output by platform:
```
## Twitter/X
- [Post 1]
- [Post 2]
- [Thread: Title]

## LinkedIn
- [Post 1]
- [Post 2]

## Instagram
- [Carousel: Title — slide-by-slide text]
- [Reel script 1]

## Email Newsletter
- [Subject line + body]

## Blog Post
- [Full article]
```

Include a suggested posting calendar: what to post when, spread over 1-2 weeks to maximize the content's lifespan.
